# অসমীয়া কেলেণ্ডাৰ ২০২৬ — Assamese Calendar 2026

An interactive web-based Assamese Calendar for the year 2026, showing all 12 months with Assamese (Saka) dates, Tithi (lunar day), Purnima (full moon), and Amabasya (new moon) information.

## 🌐 Live Demo
Deploy via GitHub Pages: `Settings → Pages → Deploy from branch (main) → / (root)`

## ✨ Features
- All 12 months with Assamese date labels
- Tithi (lunar day) for every date
- Purnima 🌕 and Amabasya 🌑 highlighted
- Today's date highlighted
- Keyboard navigation (← →)
- Responsive — works on mobile
- Pure HTML/CSS/JS — no dependencies, no build step

## 📁 Project Structure
```
assamese-calendar-2026/
├── index.html        # Main app
├── css/
│   └── style.css     # Styles
├── js/
│   ├── data.js       # All calendar data (dates + tithi)

└── README.md
```

## 🚀 Usage
Just open `index.html` in any browser. No server required.

## 📅 Calendar System
- Gregorian year 2026 CE
- Saka years 1432–1433 (অসমীয়া বৰ্ষ ১৪৩২–১৪৩৩)
- Source: Assamese Panjika 2026
